❌ CMS menampilkan "0 berita tersedia"

✅ Hapus berita test yang ter-encode
✅ Buat berita baru (akan otomatis di-decode)

====================================================================
❓ KENAPA MIDDLEWARE DecodeBase64Input DIPERLUKAN?
====================================================================

Frontend Next.js mengirim data dengan format:
{
  "judul": "b64:VGVzdCBCZXJpdGE=",    ← Ini base64 encoded!
  "konten": "b64:SW5pIGtvbnRlbg==",   ← Ini juga!
  "kategori": "Pemerintahan"          ← Ini normal
}

Middleware DecodeBase64Input akan:
1. Cek setiap string yang ada prefix "b64:"
2. Decode base64-nya
3. Replace dengan string asli
4. SKIP file upload (gambar, dll)

Hasil setelah middleware:
{
  "judul": "Test Berita",             ← ✅ Decoded!
  "konten": "Ini konten",             ← ✅ Decoded!
  "kategori": "Pemerintahan"          ← Tetap sama
}

🐛 TROUBLESHOOTING
====================================================================

Q: Setelah upload masih error 500?
A: Cek show-latest-log.php untuk lihat error detailnya

Q: Middleware tidak jalan?
A: Pastikan clear-cache.php sudah dijalankan

Q: Berita masih b64: setelah perbaikan?
A: Itu berita LAMA yang ter-encode di database.
   Hapus dan buat baru, atau update manual di database.

Q: CMS masih "0 berita tersedia"?
A: Coba hard refresh browser (Ctrl+Shift+R)
   Atau cek test-berita-api.php untuk lihat API response
