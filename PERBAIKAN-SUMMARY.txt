🔧 TROUBLESHOOTING COMMON ERRORS:
═══════════════════════════════════════════════════════════════════════════════

ERROR: "SQLSTATE[HY000] [1045] Access denied for user"
SOLUSI:
  - Double-check username/password di .env
  - Pastikan user sudah di-assign ke database di cPanel
  - Pastikan user punya ALL PRIVILEGES

ERROR: "SQLSTATE[HY000] [2002] Connection refused"
SOLUSI:
  - Ganti DB_HOST dari 127.0.0.1 ke localhost
  - Pastikan MySQL service running di cPanel

ERROR: "500 Internal Server Error"
SOLUSI:
  - Clear cache (lihat Langkah 3)
  - Check permissions: storage/ dan bootstrap/cache/ harus 755/775
  - Check error log: storage/logs/laravel.log

ERROR: "403 Forbidden" saat create berita
SOLUSI:
  - DecodeBase64Input sudah di-disable di Kernel.php
  - Pastikan file Kernel.php yang baru sudah di-upload
  - Clear cache setelah upload
