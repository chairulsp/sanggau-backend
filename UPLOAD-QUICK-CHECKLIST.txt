    ⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ Upload Error
   → File size terlalu besar? Compress jadi .zip → Upload → Extract

❌ File Tidak Replace
   → Pastikan DELETE file lama sebelum upload baru

❌ Composer Error
   → Try: php /usr/local/bin/composer install --no-dev

❌ Permission Error
   → chmod -R 755 storage bootstrap/cache
   → chmod -R 777 storage/logs public/uploads

❌ API Masih Return Relative Path
   → php artisan config:clear
   → php artisan cache:clear
   → composer dump-autoload -o
